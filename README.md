# LemonBerry

GitHub Pages Blog based on Jekyll & minima.

---

## structure

```
├── _config.yml          # 站点配置
├── Gemfile              # 本地预览用的依赖（线上构建用不到）
├── index.md             # 首页
├── about.md             # 关于页
├── 404.html             # 404 页面
├── admin/               # 网页后台（访问 /admin/）
│   ├── index.html
│   └── config.yml
├── _posts/              # 所有文章
│   └── 2026-11-05-hello-world.md
├── _drafts/             # 草稿，不参与构建
└── assets/              # 图片等静态资源
```
